| Транзакция              | Описание                                                | Тип            | Компенсация       |
| ----------------------- | ------------------------------------------------------- | -------------- | ----------------- |
| CREATE_PAYMENT          | Создание записи платежа в системе                       | повторяемая    | -                 |
| HOLD_MONEY              | Удержание средств на счете пользователя                 | компенсируемая | RELEASE_MONEY     |
| START_FRAUD_CHECK       | Отправка запроса в антифрод-систему                     | повторяемая    | -                 |
| WAIT_FRAUD_RESULT       | Ожидание результата (ответ от антифрод-системы/таймаут) | повторяемая    | -                 |
| APPROVE_PAYMENT         | Фиксация статуса "разрешено" после проверок             | повторяемая    | -                 |
| RESERVE_MONEY           | Списание средств со счёта пользователя                  | компенсируемая | REFUND_MONEY      |
| TRANSFER_TO_CONTRACTOR* | Перевод средств контрагенту                             | компенсируемая | REFUND_CONTRACTOR |
| CONFIRM_PAYMENT         | Завершение платежа и фиксация успешного статуса         | необратимая    | -                 |
| REJECT_PAYMENT          | Фиксация статуса "отклонено"                            | повторяемая    | -                 |
| RELEASE_MONEY           | Вернуть удержанные средства                             | необратимая    | -                 |
| REFUND_MONEY**          | Возврат средств пользователю                            | необратимая    | -                 |
| REFUND_CONTRACTOR**     | Возврат средств от контрагента                          | необратимая    | -                 |
| SEND_NOTIFICATION       | Уведомление пользователя о статусе                      | повторяемая    | -                 |
| SEND NOTIFICATION       | Отправка нотификации                                    | повторяемая    | -                 |
\* Операция, являясь, по сути необратимой(деньги уже ушли контрагенту), на уровне Saga является компенсируемой через отдельное бизнес-действие/Saga: `REFUND_CONTRACTOR`
** Операция должна быть реализована на retry механизмах и быть идемпотентной
